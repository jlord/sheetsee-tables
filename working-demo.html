📚 How to Use Sheetsee Tables

Here's a quick example of how to create your own table:

// 1. Prepare your data var myData = [ {"Name": "John", "Age": "25", "City": "New York"}, {"Name": "Jane", "Age": "30", "City": "Los Angeles"} ]; // 2. Create your table var tableOptions = { "data": myData, "pagination": 10, "tableDiv": "#myTable", "filterDiv": "#myFilter", "templateID": "myTable_template" }; // 3. Initialize the table Sheetsee.makeTable(tableOptions); Sheetsee.initiateTableFilter(tableOptions);

For a complete step-by-step guide, see the Step-by-Step Manual.
